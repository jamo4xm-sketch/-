# ميدالية شعار جامعة التقنية والعلوم التطبيقية (أبيض + أسود)

الشعار وحده بدون الكتابة. قاعدة سوداء وفوقها الشعار بارز بالأبيض، والألوان طبقات (تغيير لون واحد بس لكل لوحة).

| | |
|---|---|
| المقاس | 20.4 × 28.4 مم، السماكة 2.4 مم |
| القاعدة السوداء | 1.6 مم (8 طبقات) |
| الشعار الأبيض | 0.8 مم (4 طبقات، عشان الأسود ما يبين من تحت الأبيض) |
| فتحة الحلقة | 3.6 مم (تناسب الحلقة المعدنية أو السلسلة) |
| الوزن | تقريباً 1–1.2 غرام للحبة |

## الملفات (`out/`)
- `UTAS_keychain_P2S_PLA_AMS.3mf`: مشروع Bambu Studio جاهز (حبة وحدة). أسود ← أبيض تلقائياً بالـ AMS عند الطبقة 9
- `UTAS_keychain_P2S_PLA_noAMS.3mf`: نفس الشي بدون AMS. الطابعة توقف عند الطبقة 9 عشان تحط الأبيض بيدك
- `UTAS_keychain_P2S_PLA_FULLBED_70pcs_AMS.3mf` و`..._noAMS.3mf`: بد كامل فيه 70 حبة، جاهز Slice ثم Print
- `keychain_single.stl`: ميدالية وحدة
- `plate_30pcs.stl`: 30 حبة مرتبة على اللوحة
- `plate_70pcs_full.stl`: 70 حبة، لوحة P2S كاملة (أقل هدر للحبة الوحدة)
- `keychain_base_black.stl` و`keychain_logo_white.stl`: الجزئين منفصلين (اختياري، للتلوين بالأجزاء)
- `preview.png`: صورة معاينة

## إعدادات Bambu Studio (P2S، نوزل 0.4، PLA)
1. اختار الطابعة **Bambu Lab P2S 0.4 nozzle**، والبروفايل **0.20mm Standard**.
2. استورد ملف اللوحة واضغط **Yes** إذا سألك يقسمه لأجزاء. لا ترتب من جديد.
3. **Quality**: ارتفاع الطبقة 0.2، والطبقة الأولى 0.2.
4. **Strength**: الجدران (Wall loops) 2، الطبقات العلوية (Top shell layers) 4، الطبقات السفلية (Bottom shell layers) 3، والحشوة (Sparse infill) 15%.
5. **Support**: مقفل. **Brim**: مقفل (None).
6. **Others**: قفّل **Prime tower** لأنه ما نحتاجه مع تغيير لون واحد، وهذا يوفر فيلمنت.
7. اختياري: **Ironing ← Top surfaces** عشان الأبيض يطلع ناعم ولامع (يزيد الوقت شوي).
8. خلّ كل الأجسام على **فيلمنت 1 = أسود**.
9. اضغط **Slice**، وبعدها بشاشة **Preview** حرّك الشريط العمودي للطبقة **9 (Z = 1.80)**. اضغط كليك يمين على علامة **+**، واختر **Add color change**، واختار الأبيض.
   - مع AMS: يبدّل اللون بروحه مرة وحدة بس.
   - بدون AMS: اختار **Add pause** بدال تغيير اللون. الطابعة توقف، تبدّل الأسود بالأبيض يدوياً، وتكمّل.
10. اطبع على اللوحة المحببة (Textured PEI) أو أي لوحة نظيفة.

## تعديل التصميم
الإعدادات موجودة فوق في ملف `make_keychain.py` (المقاس والسماكات والفتحة). شغّل الأوامر هذي:
```
pip install opencv-python-headless shapely trimesh mapbox_earcut manifold3d matplotlib
python3 make_keychain.py && python3 make_plate.py && python3 render_preview.py
```
